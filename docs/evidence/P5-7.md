# P5-7 — Local reminders

- [ ] OWNER — Install the current Android development build on a physical
  phone. Record the phone model, Android version, and check date when running
  this checklist.
- [ ] OWNER — Open Pawlaris, create a task with a reminder three minutes
  ahead in the family timezone, and enable reminders from the notification
  rationale screen. Record the planned reminder time.
- [ ] OWNER — Before the reminder fires, run `adb shell dumpsys alarm`.
  Keep an excerpt for `app.pawlaris` showing the scheduled trigger time and
  that the alarm is exact (`window=0` or `windowLength=0`).
- [ ] OWNER — Lock the physical phone and wait for the reminder. Confirm
  the notification arrives within the scheduled minute. Record its displayed
  time alongside the planned reminder time.
- [ ] OWNER — Add the exact-alarm excerpt and the notification time as text
  under the relevant checklist steps. Keep phone media out of the repository.
