# P5-3 — Completion reaches the other phone

Procedure from `spec/08-tasks.md` P5-3 and `spec/07-test-harness.md` §13.
All device steps below are OWNER. No phone result has been observed in
this session. Leave the task's Device checkbox unchanged.

Use the Motorola Edge 70 as phone A and the Samsung Galaxy S23 Ultra
(`SM-S918B`) as phone B, as listed in [devices.md](../devices.md).
For each run, record the date, both device models, Android versions,
tested commit, observed elapsed time, and the result under its checklist
item. Identify phones by model; replace serial numbers with `<serial>`
and any development-machine LAN address with `<PC-LAN-IP>` in text output.

- [ ] OWNER — Install the same current development client on both phones.
  Connect both to the same Wi-Fi network and sign in as different family
  members. Open the dashboard on today and choose scopes that show the
  same incomplete occurrence on both phones. Confirm sync is connected.
- [ ] OWNER — Start a recording showing both screens and a clock or
  stopwatch. On phone A, release the checkbox for an occurrence that does
  not require a photo. Confirm its star lights immediately, with one
  haptic, and its card moves to the completed section after about 400 ms.
- [ ] OWNER — On phone B, expand the completed section if necessary.
  Confirm the same occurrence shows as complete with phone A's member
  name and completion time within 3 seconds of A's release. Record the
  elapsed time and PASS or FAIL. If using an adb stopwatch script instead
  of a recording, save its sanitized raw output under this item.
- [ ] OWNER — Keep any recording only in the git-ignored
  `docs/evidence/media/` directory. Describe in words here what the two
  screens show and the measured delay; do not commit the recording or
  any screenshot. Include the device metadata and tested commit.

Host Jest tests do not substitute for this two-phone check. No media
was captured or added by the implementer in this session.
