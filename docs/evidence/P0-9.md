## Optional release-preview attempt

Before the development builds, attempted
`.\gradlew.bat :app:assembleRelease -PreactNativeArchitectures=arm64-v8a`
from `apps/mobile/android`. It failed on 2026-10-03:

```text
> Task :react-native-reanimated:buildCMakeRelWithDebInfo[arm64-v8a][reanimated] FAILED
ninja: error: manifest 'build.ninja' still dirty after 100 tries
686 actionable tasks: 654 executed, 32 up-to-date
BUILD FAILED in 2m 22s
```

Ninja's diagnostic reported a missing Worklets prefab CMake input in
Reanimated's `RelWithDebInfo` directory. This resembles the Windows native-build
path issue previously described by Q-4; the release variant remains
unverified. No package layout, native source or existing peer pin was
changed in P0-9. Both required development builds succeeded afterwards.

Initial capture attempts found the phones locked. Unlocking requires the
owner, who unlocked both during the session; no lock-screen capture is
included in repository evidence.
