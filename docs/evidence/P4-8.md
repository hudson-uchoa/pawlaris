# P4-8 — Hero transition device recordings

Procedure from `spec/08-tasks.md` P4-8 and `spec/07-test-harness.md` §13.
**Every step is OWNER. No step has been run and no device result has been
observed for this checklist.** Leave the task's Device checkbox unchanged.

Use the real Motorola Edge 70 and Samsung Galaxy S23 Ultra (`SM-S918B`)
listed in [devices.md](../devices.md). Capture five complete grid → profile
→ grid round trips per phone per theme: four recordings, twenty round trips.
This is a visual check; P7-4 measures the numeric frame budget.

When completing a step, append its date, device model, Android version,
raw command output and recording reference beneath it. Keep serial numbers
and LAN addresses out of committed evidence: substitute `<serial>` and
`<PC-LAN-IP>` locally only. Run PowerShell commands separately and stop on
a non-zero exit. Start terminals at the repository root.

- [ ] OWNER — For each phone, select its serial locally, record its model
  and Android version, and enable the Metro USB transport. Turn Android's
  Remove animations setting off and use normal animation scales for these
  recordings. Clear obstructing dialogs and open the Pets grid.

  ```powershell
  $deviceId = '<serial>'
  adb -s $deviceId shell getprop ro.product.model
  adb -s $deviceId shell getprop ro.build.version.release
  adb -s $deviceId shell getprop ro.build.version.sdk
  adb -s $deviceId reverse tcp:8081 tcp:8081
  ```

Each capture below includes this entire flow. Set the specified Android
theme, verify Pawlaris follows it, and start recording with the commands
below. Repeat the round trip exactly five times, counting in the result
notes. Hold a pet card briefly: only its press scale should change. Release
it: the avatar and name should travel from the card into the header without
a separate native slide. The name scales without reflow. The starfield and
body fade in underneath; the header takes over cleanly and its orbit
satellite begins only after the travel settles.

Wait for settle, then use Android's system Back button or completed system
Back gesture. The copies should return to the card's current frames, then
disappear. Confirm the grid's avatar and name are restored without a blank
card or duplicate copy. Between trips, scroll the grid and select a card
at a different position to exercise re-measurement. If a source is no
longer measurable, expect the short crossfade, without a jump from a stale
frame. Finish each recording on the grid after the fifth return and check
that no overlay remains. Do not use an app control as a substitute for
system Back.

Use a second repository-root terminal for recording and retrieval. Set
`$deviceId` to the current phone and `$captureName` to the name in its
checkbox. While `screenrecord` runs, perform the five trips on the phone;
press Ctrl+C after the fifth return, then retrieve the recording.

```powershell
$deviceId = '<serial>'
$captureName = '<capture-name>'
adb -s $deviceId shell screenrecord --time-limit 180 "/sdcard/$captureName.mp4"
adb -s $deviceId pull "/sdcard/$captureName.mp4" "docs/evidence/media/$captureName.mp4"
```
