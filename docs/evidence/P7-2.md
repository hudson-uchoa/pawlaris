# P7-2 — Both themes and accessibility audit

Every step is OWNER and requires both physical Android phones with a build
containing P7-2. No step has run; no result is recorded. Leave every step
unchecked until performed. Record the date, phone model, Android version,
build and observations under each step only after performing it.

Identify phones by model only. Use `<serial>` in commands and retained
output, never a real serial. Use `<PC-LAN-IP>` for a development server's
address. Keep every screenshot only in the git-ignored
`docs/evidence/media/` directory; never add captures to the repository.
Describe screenshots in words here without personal data or locations.

- [ ] OWNER — On each phone, confirm the installed build. Read the model
  with `adb -s <serial> shell getprop ro.product.model` and Android version
  with `adb -s <serial> shell getprop ro.build.version.release`. Retain only
  model and version. Sign in as different members of the same family.
- [ ] OWNER — Record each phone's original font scale and theme settings.
  Set 130% font scale with
  `adb -s <serial> shell settings put system font_scale 1.3`.
  Read it back with
  `adb -s <serial> shell settings get system font_scale`.
  Reopen the app and keep 130% for every capture below.
- [ ] OWNER — Prepare the family data needed to reach each screen: a pet,
  weight, health event, task with photo proof, completed photo proof and
  finished walk. Use expendable records for edit flows. Keep captures of
  maps and photos local, as they can contain private locations or images.

Repeat every capture step below on both phones. For each theme, select
that theme in Android settings, reopen the app and navigate using the app's
controls. On each listed screen, capture all content, scrolling as needed;
on forms also capture the focused last field and primary action with the
keyboard open. Confirm readable text, no clipping or overlap, visible
actions and 44 dp touch targets. Describe any issue under the relevant step.
For a capture, use `adb -s <serial> shell screencap -p /sdcard/P7-2.png`,
then `adb -s <serial> pull /sdcard/P7-2.png` with a destination under
`docs/evidence/media/`. Name local files by phone model, theme and screen.
