# P6-1 — Location permissions

All checks require the owner's physical Android 14+ phone. When executing
each item, record the date, phone model, Android version, visible screen,
permission state and raw command output beneath it. Keep serials and network
addresses out of this file; use `<serial>` and `<PC-LAN-IP>` placeholders.
No device results are recorded here.

- [ ] OWNER — Record the model and Android version of the physical phone.
  Run `adb -s <serial> shell getprop ro.product.model` and
  `adb -s <serial> shell getprop ro.build.version.release`. Use the phone,
  not an emulator, for every following step.
- [ ] OWNER — Install the current Android development build, rebuilt with
  the location plugin and manifest changes. Use disposable development app
  data for both passes below. Before clearing storage for either pass, sync
  any family changes; do not discard unsynced records. Record the build used.

## Pass A — Precise selection

- [ ] OWNER — Clear the disposable app's storage in Android app settings,
  reopen Pawlaris and sign in. Leave location and notifications ungranted.
  Dismiss any task-reminder rationale without granting notifications. Open
  the app's Settings tab, then Permissions. Record the initial location,
  background-location and battery states shown.
- [ ] OWNER — Tap the Location row to open `permission/location`. At this
  phase, enter through Settings; the walks tab is still a placeholder.
  Record the location rationale, the precise-location instruction and the
  single primary button. Confirm no system dialog appears before pressing it.
- [ ] OWNER — Press the location button. In Android's dialog choose precise
  accuracy and allow location while using the app. Record the selection and
  the next screen shown: the notification rationale, with no cold dialog.
  Record the location grant after this step.
- [ ] OWNER — Press the notification button and grant notifications in the
  system dialog. Record the notification grant and the next screen shown:
  the battery rationale, with two manufacturer-specific help lines. Compare
  the help with the phone's manufacturer and record the visible content.
- [ ] OWNER — Press the battery settings button. Find Pawlaris and disable
  battery optimization, then return to the app. Record the screen and states
  shown after this step. On the Permissions screen, inspect the location,
  background-location and battery rows; location should report `granted`.
  Confirm the normal flow offered no background-location request or step 3b.
- [ ] OWNER — Close and reopen the app. Record the permission rows again.
  Revoke foreground location in Android app settings, return to Pawlaris,
  and reopen the ladder through the Location row. Grant precise location
  again. Record that the granted notification step and completed battery
  prompt are skipped, and record the state shown after returning.

## Pass B — Approximate selection

- [ ] OWNER — Prepare a fresh disposable app state as in Pass A: clear its
  storage only after syncing any family changes, sign in, and leave location
  and notifications ungranted. Record the initial permission rows. Open the
  ladder through Settings, Permissions, Location.
- [ ] OWNER — Press the location button. Choose approximate accuracy and
  allow location while using the app. Record the selection and the screen
  shown after this step: the explanation requiring precise location and a
  Settings button. Confirm the ladder does not advance to notifications or
  battery and does not offer walk recording with this grant.
- [ ] OWNER — Return to the phone's home screen, then foreground Pawlaris.
  Record that the precise-location explanation remains. Close the rationale
  with Back and record the Location row's `approximate` state. Reopen the
  app once more and record the state shown without another native request.
- [ ] OWNER — Reopen the location rationale directly with
  `adb -s <serial> shell am start -a android.intent.action.VIEW -d pawlaris://permission/location app.pawlaris`.
  Press its Settings button. Enable precise location in Android settings,
  return to Pawlaris and record the state and next screen after foreground:
  the notification rationale should replace the precise-location gate.
- [ ] OWNER — Grant notifications from their rationale, then open battery
  settings from the battery rationale. Record each screen, the grant shown
  after each step and both manufacturer help lines. Return to Pawlaris and
  record the final location, background-location and battery row states.
  Confirm the normal ladder still contains no step 3b or background request.
