# P8-2 device evidence

The box was not available during implementation. Every device check remains
`OWNER`; no emulator, local machine, or substitute host is valid.

- [ ] OWNER — From the box, run `sudo tailscale up` and complete the owner's
  login; record `<BOX_TSNET_NAME_PLACEHOLDER>`.
- [ ] OWNER — On the box, run `sudo tailscale serve --bg --https=443
  http://127.0.0.1:8000` and `sudo tailscale serve status`; confirm the config
  is present after a reboot.
- [ ] OWNER — On both phones, enable Tailscale and use the release build with
  `EXPO_PUBLIC_API_URL=https://<BOX_TSNET_NAME_PLACEHOLDER>/api/v1`.
- [ ] OWNER — From a phone using mobile data, with Tailscale on, request
  `GET https://<BOX_TSNET_NAME_PLACEHOLDER>/api/v1/health`; expect HTTP `200`.
- [ ] OWNER — From a computer on the tailnet, obtain a real access token by
  logging in, then run this one-line Node 22 client. Paste the token only at
  the prompt; it is not written down. Expect a JSON frame with `type` `ready`:

  ```sh
  node -e "const readline=require('node:readline/promises');const rl=readline.createInterface({input:process.stdin,output:process.stdout});(async()=>{const token=await rl.question('Access token (not saved): ');rl.close();const ws=new WebSocket('wss://<BOX_TSNET_NAME_PLACEHOLDER>/api/v1/ws');ws.onopen=()=>ws.send(JSON.stringify({type:'auth',access_token:token}));ws.onmessage=e=>{console.log(e.data);if(JSON.parse(e.data).type==='ready')ws.close(1000)};ws.onerror=()=>process.exitCode=1})()"
  ```

- [ ] OWNER — From a network that is not the family tailnet, run
  `nmap -Pn -p 22,80,443 <BOX_PUBLIC_ADDRESS_PLACEHOLDER>`; expect no listed
  ports to be open. The tailnet-only profile has no expected public port.
