- **The green commit changed no assertion.**
- **The catalogue** is `10` §3 function for function. Each queues the
  method, path and body of `04`: a create sends its `id`, `undo`, `cancel`,
  `archive`, `unarchive` and `discard` send no body, `finish` sends the
  route, and a patch sends only the fields given. Each local row is the
  whole row in the server's shape: a create fills what the server would —
  `sex 'unknown'`, `category 'other'`, `reminder_class 'routine'`,
  `completion_mode 'together'`, `sort_order 0`, as `03` gives them — with
  `revision: null` and the caller as author; an edit, an archive, an undo, a
  cancel and a finish keep the `revision` the row had *(ADR-039)*; a delete
  removes the row.
- **`enqueue`** is one transaction across the replica, the outbox and the
  store: a failure in its second insert leaves all three as they were. The
  kick comes after the commit, once, and never after a rollback, also when
  `enqueue` runs inside somebody else's transaction — it listens to the
  driver's `onTransactionEnd` and replaces nothing.
- **`forkTask`** queues the new template's create before the old one's
  patch, in one change; when the patch cannot be queued, the new template is
  not there either.
- **`drain`** is `10` §4 line by line: the head entry of the session's user,
  by `seq`; `waiting` while its retry time is ahead; the `Idempotency-Key`
  of the entry; then `ok`, `transient`, `permanent` or `auth` by `classify`.
  A transient failure counts an attempt, counts a server error only for a
  `5xx`, and sets the retry time from the backoff, or from `Retry-After` —
  seconds or a date, on a `429` or a `503` only.
- **`onAck`** writes the server's row unless another entry still targets it;
  a completion answered with another id removes the local one and every
  entry queued for it, stores the winner and announces it once, after the
  commit.
- **`reject`** writes the dead letter, removes the row unless newer intent
  targets it, removes the entry and sets the active server's cursor to zero,
  all in one transaction; a failure in the last step undoes the others; the
  announcement waits for the commit.
- **OB-1 to OB-6** hold as `10` §4 states their gates, the restarts as new
  objects over the exported database, time and jitter from the fakes.
- **Hard rules:** no clock, random or id source read directly; strict types
  with no `any`; shared types from `@pawlaris/shared`; no Portuguese — the
  events carry data and the toasts are the screens'; no dependency added.
- **Coverage floor:** 90% for `src/sync`.
