## R1 — minor — a completed constellation redraws on mount and on focus    FIXED

**Where:** `apps/mobile/src/ui/cosmos/ConstellationLine.tsx:37-43`
**Spec:** `06` §4.3
**Problem:** the effect starts the draw-on whenever `complete` is true and
the line is active, with no memory of the previous value. A card whose
occurrence was already complete draws its line again each time it mounts
and each time its screen regains focus or the app returns to the
foreground: opening the dashboard replays every finished constellation.
`06` §4.3 draws the line *when the last pet is completed* and then keeps
it. `StarCheck` already gets this right by comparing with the previous
`checked`.
**Fix:** animate only on a `complete` false → true change seen while
active (as `StarCheck` does); on mount, on a return to activity and under
Reduce Motion, show the finished line still. Add the cases: mounted
complete and active → no `withTiming`, offset 0; complete, inactive, then
active → no draw-on.

FIXED in 49ab0db — the line animates only on a false → true change seen
while active; three cases cover a completed mount and completion while
unfocused or backgrounded. Verify on that tree: 14 pass, 0 fail.
