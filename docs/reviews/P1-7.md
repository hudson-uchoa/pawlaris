## R1 — minor — two malformed values no test tries                      FIXED

FIXED in 8400917. VL-15 rejects a non-hexadecimal letter and misplaced
hyphens in 36-character UUIDs across all six reference fields; VL-13 rejects
`+01:00` in both instant fields. Each of the 14 new invalid-value assertions
failed when its guarded pattern was weakened, killing all three mutations.
`validators.ts` was restored byte-for-byte. The P1-7 gate passed 135 tests;
`pnpm verify --allow-pending` reported 13 pass, 0 fail, 1 pending of 14.

**Where:** `packages/shared/src/validators.test.ts` — VL-13 (`:167`), VL-15
(`:196`)
**Spec:** `07` §4.6 as extended with this review; the answer to Q-12
**Problem:** the code is right, and two weaker versions of it pass every
test:

1. **A reference of 36 characters that is not a UUID.** The malformed
   references tried are all shorter; with the pattern removed and only the
   length checked, nothing fails.
2. **An instant ahead of UTC.** `-03:00` is tried and rejected; `+01:00` is
   not, and a pattern accepting any positive offset passes.

**Fix:** one commit of tests, no change to `validators.ts`: VL-15 rejects a
36-character string with a letter outside `0-9a-f` and one with its hyphens
misplaced; VL-13 rejects `+01:00`. Confirm each by weakening the pattern it
guards and watching the test fail.
