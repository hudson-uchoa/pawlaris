## R1 — minor — two rules of a reconnecting socket that no test holds   FIXED

**Where:** `apps/mobile/src/sync/__tests__/socket.test.ts`
**Spec:** `10` §6; P3-6's Build line
**Problem:** two mutants survive, and the code is right in both. (a)
`close()` not moving to a new run: a token lookup or a refresh started
before `close()` that ends after a new `connect()` would open a second
transport. The tests close and then never connect again. (b) `connect()`
not refusing a second call: while connecting or open, a second `connect()`
would open a second transport.
**Fix:** tests only. (a) Close while a refresh or a token lookup is
pending, connect again, then let the old one finish: one transport, the new
one. (b) `connect()` twice, while connecting and while open: one transport.
