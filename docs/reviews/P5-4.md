## R1 — minor — Per-pet history rows are untested                 OPEN
**Where:** `apps/mobile/src/features/tasks/taskHistory.ts:27`
**Spec:** `09` §5.3 (per row), `03` completion `pet_id`
**Problem:** a `per_pet` task has one slot per pet, and its history
lists one row per pet. Collapsing every task to the single `together`
row survives every test.
**Fix:** a history test on a `per_pet` task with two pets, one done and
one not, asserting two rows for the slot. The done row has its
attribution; the other row is `não feito`.

## R2 — minor — Reseed duplicates are not excluded by any test     OPEN
**Where:** `apps/mobile/src/features/tasks/taskHistory.ts:19`
**Spec:** `03` task_completion `duplicate_of` (set only by a reseed)
**Problem:** dropping the `duplicate_of` check survives every test. A
duplicate in the same slot would then replace the canonical
completion's attribution in the row.
**Fix:** a test with a canonical completion and a duplicate of it in
one slot, by different members. The row shows the canonical one, and
the slot appears once.

## R3 — minor — Loaded pages after an undo are untested            OPEN
**Where:** `apps/mobile/src/features/tasks/TaskDetailScreen.tsx:93`
**Spec:** `09` §5.3 (undone completions are not listed), R3.22
**Problem:** the history memo depends on the replica's completions so
that an undo, local or synced, refreshes pages already loaded. Removing
that dependency survives every test: the undone row would keep its
attribution until the screen remounts.
**Fix:** render the detail with a done row in the history, undo that
completion through the replica, and assert the row turns `não feito`
without remounting.

## R4 — minor — Hoje could show other days' occurrences           OPEN
**Where:** `apps/mobile/src/features/tasks/TaskDetailScreen.tsx:75`
**Spec:** `09` §5.3 (Hoje: today's occurrences of this template)
**Problem:** the day view also carries overdue occurrences from earlier
dates. Removing `item.originalDate === today` survives every test, so
an overdue slot from yesterday could appear under **Hoje**.
**Fix:** a detail test with an overdue slot from yesterday and a slot
today: **Hoje** lists only today's.

## R5 — minor — The history photo thumbnail is untested            OPEN
**Where:** `apps/mobile/src/features/tasks/TaskDetailScreen.tsx:143`
