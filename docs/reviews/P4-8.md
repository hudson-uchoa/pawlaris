## R1 — minor — three of the measure checks are untested                FIXED

**Where:** `apps/mobile/src/ui/motion/hero/geometry.ts:4-17`
**Spec:** `06` §4.6 ("a failed measure (null or zero size)"; "if the
source card is no longer on screen, crossfade")
**Problem:** `measureFrames` refuses a frame of zero size, a frame
outside the window, and a pair where only the name failed. The cases
cover a `null` source, a `null` target and an unmounted source, but none
of these three. Each survives on its own:

- `zero size accepted`;
- `off-screen source accepted`;
- `name frame ignored`.

A card scrolled out of the grid while the profile was open is the
common case on the phone. It would then animate from off the screen
instead of crossfading.
**Fix:** extend the null-measure `test.each` with three rows, each
asserting the crossfade path (no spring, `duration.reducedFade`) and a
clean unmount:

- a zero-width source avatar;
- a source avatar whose `pageY` is past the window's height, on Back;
- a `null` name with a valid avatar.

FIXED in `1761573`.
