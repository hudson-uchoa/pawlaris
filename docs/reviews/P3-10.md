A phone arriving at a server now heals it: it sends what it holds in the
entity order, pulls everything again under a new generation, and removes
only what neither the server nor its queue keeps — never before the pull
has ended. A row edited while its server was gone travels with the edit,
so the edit does not cost the row. Accepted, with no finding.
