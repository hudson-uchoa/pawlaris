## What the spec got wrong (the orchestrator's)

- **`11` §4.3 would have lost rows.** It left every row with an outbox
  entry out of the reseed. For an edit, an archive, an undo or a cancel of a
  row one server had acknowledged, a server that lacks the row answers
  `404`, the rejection removes the row from the phone, and the rows naming
  it are refused and swept before that. ADR-039 (`fd959dd`) changes the
  rule: a row stays out only while no server has acknowledged it, and a walk
  with a queued mutation waits for the outbox. `pageForReseed` here is
  correct to the rule it was given; P3-10 changes its filter.
- **`10` said two things about a local row's `revision`** — null in §3,
  untouched in §2.3. It is the one its replica row had; the reseed now
  depends on it.
- **The task did not name its packages**, nor say that `sql.js` needs
  declarations (`2f70080`).
