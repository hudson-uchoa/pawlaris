**Spec:** `08` P0-6 Build and Device; `05` §1 "Native versions come from the

**Problem:** `npx expo run:android` fails at
`:react-native-reanimated:assertWorkletsVersionTask`. pnpm installs
Reanimated on its own, as a peer of `expo-router`, and takes the newest,
4.7.1; the overrides pin Worklets to 0.10.1. Reanimated 4.7.x requires
Worklets 0.13.x. Checked by the reviewer: the installed SDK's
`expo/bundledNativeModules.json` names Reanimated 4.5.1 with Worklets 0.10.1,
and Reanimated's `compatibility.json` lists 4.5.x with Worklets 0.10.x on
React Native 0.86. The mismatch comes from P0-5, whose review ran a
JavaScript export and never the native check; it surfaces here because this
is the first native build.
**Fix:** as answered in Q-3 — add `react-native-reanimated: 4.5.1` to the
root overrides, regenerate the lockfile, and confirm no other installed
native module differs from `bundledNativeModules.json`. Then run every open
step of `docs/evidence/P0-6.md` on both phones, and remove the "Current
blocker" paragraph and the `assertWorkletsVersionTask` row from
`docs/build.md` once the build passes.
